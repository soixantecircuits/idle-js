# Security Policy

## Supported Versions

| Version | Supported                            |
| ------- | ------------------------------------ |
| 2.x     | :white_check_mark:                   |
| 1.x     | security fixes only until 2.0 stable |

## Reporting a Vulnerability

Open a GitHub Security Advisory on this repository. Do not open a public issue
for unpatched vulnerabilities. Expect an initial response within 72 hours.
